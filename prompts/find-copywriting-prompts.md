# Task: Find Twitter/LinkedIn Copywriting Prompts

## Goal
Find high-quality copywriting prompts for Twitter and LinkedIn content that generates leads (not just engagement).

## Criteria

### Must have:
- Prompts for Twitter: hooks, threads, engagement replies
- Prompts for LinkedIn: posts, carousels
- Lead generation focus (CTA that converts)
- Founder/entrepreneur voice (not corporate)
- Examples of actual prompts (not just tips)

### Nice to have:
- Templates that use real founder language
- Prompts that validate pain points
- CTAs for booking calls

## Output format

For each prompt found:
1. Source URL
2. Full prompt text
3. What it does (hook, thread, etc.)
4. Why it's good

## Where to search
- GitHub (search "twitter prompt", "linkedin prompt", "copywriting prompt")
- AI prompt marketplaces
- Twitter threads about prompts
- LinkedIn posts about viral content
- Reddit r/ChatGPT, r/promptengineering

## Deliverable
Create a document with all useful prompts found, organized by platform and use case.
