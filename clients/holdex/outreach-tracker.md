## How to Use

1. Open LinkedIn → click the 🔗 link for each lead
2. Click "Connect" → paste `connection_message`
3. Update Stage: `new` → `reached`
4. Day 3-5: Check for responses, send follow-up if no reply → update `followup_message`
5. Day 10: Send breakaway if still no response → update `breakaway_message`
