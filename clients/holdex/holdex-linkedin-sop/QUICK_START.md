# Quick Start Guide

## Holdex LinkedIn Lead Management — Get Started in 15 Minutes

---

## Day 1: Set Up (15 minutes)

### 1. Review Your Invitations

Open LinkedIn → Notifications → Invitations

Review each pending connection request:

- Who are they?
- What do they do?
- Is it relevant?

### 2. Classify Each Lead

Use the 4-Tier system:

| Tier | Symbol | When to Use |
|------|--------|-------------|
| Hot | 🔥 | Active Web3 project, technical founder, needs co-building partner |
| Warm | ⭐ | Relevant but not immediate fit |
| Nurture | 📌 | Investors, service providers, ecosystem players |
| Pass | ❌ | Job seekers, unrelated industries, spam |

### 3. Log in Attio (Create Records)

For each Tier 1 and Tier 2 lead, create a record in Attio:

- Name
- LinkedIn Profile URL
- Lead Tier
- Lead Source = LinkedIn Inbound
- Stage = New
- Next Action Date = Today + appropriate days

### 4. Send First Message

Use templates from `templates/TEMPLATE_LIBRARY.md`:

- **Tier 1**: Use "Initial Outreach — Project Focus"
- **Tier 2**: Use "General Warm — Keep in Touch"
- **Tier 3**: Use appropriate nurture template

---

## Daily Routine (15-30 min)

### Every Morning

1. **Check LinkedIn** (5 min)
   - New connection requests?
   - Responses to your messages?

2. **Review Attio Tasks** (5 min)
   - Today's Follow-ups
   - Any hot leads needing immediate response?

3. **Take Action** (5-15 min)
   - Respond to new Tier 1 leads (same day!)
   - Send follow-ups
   - Log everything in Attio

### Weekly (30 min, Monday recommended)

1. **Pipeline Review**
   - Check each lead's stage
   - Move leads forward or mark as closed

2. **Metrics**
   - How many new leads?
   - How many meetings booked?

## Most Important Rules

1. **Respond to Tier 1 (Hot) leads SAME DAY** — Speed matters in Web3

2. **Log everything in Attio** — If it's not logged, it didn't happen

3. **15-30 minutes max per day** — Consistent small actions beat sporadic big efforts

4. **Manual only** — No automation tools to protect LinkedIn account
