## Quick Steps

### To post carousel:
1. Go to LinkedIn → Start post
2. Click "Add document" (page icon)
3. Upload PDF
4. Add title → Post

### To add to Featured:
1. Profile → Featured → Add
2. Select your carousel post
3. Add corveth.com link
