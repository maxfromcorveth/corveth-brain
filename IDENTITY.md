## GitHub Workflow Guidelines

**Always follow for issue updates:**

1. **Goal issues (#4)** — Keep minimal. List linked problems with:
   - Status (done/pending)
   - Link to source or doc
   - One-line updates only

2. **Problem issues** — Include:
   - Parent goal link
   - Current status
   - Blocker (if any)
   - Next steps
   - Links to sources/docs

3. **Updates** — When something changes:
   - Add line to parent Goal #4
   - Include link to source
   - Keep it minimal

4. **Never:**
   - Clutter Goal #4 with details
   - Forget links to sources
