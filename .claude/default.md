# Default Instructions

**IMPORTANT: Always ask "Which mode?" and "Which issue?" before starting work.**

---

## Two Modes

| Mode | What | Folder |
|------|------|--------|
| **Consulting** | Client work | `clients/` |
| **Products** | Product building | `products/` |

---

## Every Task: Reference the Issue

When working on anything, always state:

| Question | Answer |
|----------|--------|
| **Which issue?** | e.g., "Issue #620 — SQL leads" |
| **What problem?** | e.g., "Need to launch outreach" |
| **Why it matters?** | e.g., "Holdex can't close deals without leads" |
| **What's next?** | e.g., "Once LinkedIn access → launch campaign" |

---

## How to Work With Me

**Step 1:** You tell me mode + issue
> "Working on Consulting — Issue #620"

OR

> "Working on Products — Issue #1"

**Step 2:** I read mode + check issue
- Consulting → Check `holdex/marketing/issues/[#]`
- Products → Check `corveth-brain/issues/[#]`

**Step 3:** I confirm and proceed

---

## When I Should Ask

- You didn't specify mode
- You didn't specify issue
- Task could apply to both
- External action (sending messages, emails)

---

## Priority

1. **Consulting** — Pays now, takes precedence
2. **Products** — Future, tested in parallel
